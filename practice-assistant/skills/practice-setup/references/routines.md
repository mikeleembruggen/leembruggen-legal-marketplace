# Routines menu

Offer these during setup. For each one the user picks, create a Cowork scheduled task with the name, cadence and prompt below (adjust times to what they choose). All times are the user's local time.

| # | Name | Suggested cadence | Prompt |
|---|---|---|---|
| 1 | Morning brief | Weekdays 7:30am | Run my morning triage for today and put the result at the top of this task's output. |
| 2 | Dashboard refresh | Weekdays 7:40am (after the brief) | Refresh my practice dashboard, updating the existing dashboard artifact rather than creating a new one. |
| 3 | Deadline radar | Mondays 7:00am | List every key date in the next 21 days across all open matters, grouped by week, with its source. Mark anything computed as "to verify". Flag any matter with a date in the next 7 days that has no draft or recent activity. |
| 4 | Unfiled attachments check | Weekdays 4:30pm | Find email attachments received today that aren't yet filed in their matter folder. File the ones you can match confidently using the file-to-matter rules and list the rest for me to confirm. |
| 5 | Weekly matter review | Fridays 2:00pm | For each open matter, give one line: status, last activity, next action, and whether anything is overdue. Then list matters with no activity in 21+ days. |
| 6 | Awaiting-reply chaser | Wednesdays 9:00am | List emails I sent in the last 14 days on client matters that haven't had a reply, oldest first, and offer to draft polite follow-ups. Don't send anything. |

Recommended starter set: 1, 2 and 3. They can add the rest later by saying "add the weekly matter review routine".
